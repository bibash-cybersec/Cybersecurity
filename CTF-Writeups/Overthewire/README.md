# 🐧 OverTheWire Bandit

> My progress and learning notes from the **Bandit wargame by OverTheWire**.

## 🎯 About Bandit

Bandit is a beginner-friendly Linux-based wargame designed to teach the fundamentals of working with a Linux command line.

I am using Bandit to strengthen my practical Linux and command-line skills as part of my cybersecurity learning journey.

### Skills I am developing

* Linux command line
* SSH
* File and directory navigation
* File permissions
* Searching and filtering
* Pipes and redirection
* Text processing
* Processes
* Environment variables
* Networking fundamentals
* Basic Bash usage
