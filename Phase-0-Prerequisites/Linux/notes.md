# Linux Notes - Phase 0 [09 Aug 2026]

### Linux Commands I Practiced
| Command | What It Does | Example |
|---------|-------------|---------|
| pwd | Shows current directory | pwd |
| ls -la | Lists files with details | ls -la /home |
| cd | Change directory | cd /etc |
| cat | Show file contents | cat /etc/passwd |
| mkdir | Make directory | mkdir myfolder |
| grep | Search for text | grep "root" /etc/passwd |

### Important File Locations
- /etc/passwd = User accounts
- /etc/shadow = Password hashes
- /home = User home directories
- /var/log = Log files
