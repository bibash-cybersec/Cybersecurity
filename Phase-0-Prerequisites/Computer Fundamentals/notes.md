## CPU - Central Processing Unit 
CPU is most likely brain of the computer, it handles all the programs process and run

## RAM - Random Access Memory
RAM is volatile memory or temporary memory because its get erased every thing on it after the power cut off, it gives programs memory to perform certain task

## Storage Devices(HDD/SSD)
Storage devices are the devices that gives permanent memory to save data,files, or programs 
note: HDD- Hard Drive Disk SSD- Solid State Drive

## Motherboard
Its like a nerve system of a computer, it gives electrical pathways and connectors to communicate CPU, RAM, SSD to share data.

## GPU-Graphical Processing Unit 
It process all graphics programs 

## Input/Output Devices
Input device are those which receive data from the user like keyboard, mouse, microphones, webcamera etc.
Output device are those which shows data to the user like monitor, Projector, printer etc.
